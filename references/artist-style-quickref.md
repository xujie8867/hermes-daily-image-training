## 已验证 Prompt 锚点（可直接复制）

### Wu Guanzhong (吴冠中)
```
in the artistic style of Wu Guanzhong (吴冠中) — bold black ink brushstrokes, vibrant abstract dots of red/gold/green, East-meets-West modern Chinese painting aesthetic
```
配合城市海报：河流以墨线斜穿构图分割古今，左传统（城墙/古寺/渔船）右现代（CBD/摩天楼/现代桥），4信息框 + 顶部大字标题 + 底部标语 + 红印。梧桐/银杏落叶以彩点泼洒。

### James Jean (简明)
```
in the artistic style of James Jean (简明) — intricate flowing linework, surreal dreamlike composition, delicate botanical motifs intertwining with architecture, ethereal coral pink/sage green/gold palette, textile-like patterns
```
配合城市海报：梦幻长卷构图，上段漂浮莲池→中段精灵/丝带/金鱼→下段现代蜕变，藤蔓/花瓣自然形成文字框

### Hayao Miyazaki (宫崎骏)
```
in the artistic style of Hayao Miyazaki and Studio Ghibli — warm nostalgic atmosphere, soft watercolor backgrounds, lush greenery, magical realism, golden hour sunlight, big white clouds, hand-drawn textures
```
配合城市海报：大片棉花云+金色逆光，标志性小精灵（kodama/竹叶精灵/动物幼崽）做彩蛋，文字框做成木质公告板/藤蔓牌子/魔法书/竹编篮子样式。成都专用：熊猫喝茶+竹椅+盖碗茶精灵+银杏叶精灵。

### Katsushika Hokusai (葛饰北斋)
```
in the artistic style of Katsushika Hokusai (葛饰北斋) — ukiyo-e woodblock print style, bold black outlines, flat color fields (indigo blue iro-ai, ochre, cream white, vermilion), visible wood grain texture, floating world composition, influence of "Thirty-six Views of Mount Fuji"
```
配合城市海报：上层远山/云浪翻卷，下层水域/渔舟/地标，靛蓝四色平涂，浮世绘分割构图，红日+木刻版画肌理，4信息框可选米白/浅蓝底交替。桂林专用：喀斯特山峰=富士山三十六景构图，漓江水面=浮世绘浪花纹，竹筏+渔翁+鸬鹚前景。

### Caravaggio (卡拉瓦乔)
```
in the artistic style of Caravaggio (卡拉瓦乔) — extreme chiaroscuro, tenebrism, dramatic single light source from upper left, deep darkness covering 60%+ of frame, warm amber-to-umber oil paint tones, baroque theatrical tension, realistic figure rendering, visible canvas texture, 17th-century oil painting brushstrokes
```
配合城市海报：全黑背景+一束戏剧光从左上角斜射，主体（兵马俑/古迹）从黑暗中浮现，信息框做巴洛克金色卷轴状悬浮，暗色底+金色点缀营造神圣感，暖琥珀色到深褐色调

### Moebius (Jean Giraud) 🆕
```
in the artistic style of Moebius (Jean Giraud) — clean sci-fi linework, luminous pastel-to-neon gradient palette, cyberpunk-meets-classical architecture, floating HUD data panels, ethereal light beams, cross-hatch shading
```
配合城市海报：下段历史建筑以Moebius细线勾勒，中段现代摩天楼如发光方尖碑插入云层+悬浮HUD数据面板，上段黄紫渐变天空+几何六边形云朵+斜射光束。信息框做成深蓝底霓虹边框HUD面板，配色分橙/蓝/绿三色区分板块。上海专用：外滩万国建筑+陆家嘴三件套+黄浦江数据流。杭州：西湖数据湖+发光断桥+悬浮能量塔。

## 精选风格库（12大类）

### 中国水墨
Wu Guanzhong (吴冠中), Qi Baishi (齐白石)
- 适合：国风山水、花鸟、江南水乡

### 日式动画
Hayao Miyazaki (宫崎骏), Makoto Shinkai (新海诚), Akira Toriyama (鸟山明)
- 适合：治愈、自然、奇幻、城市街景

### 赛博朋克/科幻
Moebius (Jean Giraud), Syd Mead, H.R. Giger
- 适合：未来城市、机械设计、黑暗科幻

### 超写实数字插画
James Jean (简明), Loish, Artgerm (Stanley Lau)
- 适合：人物插画、商业海报、梦幻场景

### 古典油画
Johannes Vermeer, Caravaggio, Rembrandt
- 适合：暗调戏剧光、质感、肖像

### 装饰艺术
Alphonse Mucha (穆夏), Norman Rockwell, Maxfield Parrish
- 适合：复古海报、华丽边框、品牌视觉

### 浮世绘
Katsushika Hokusai (葛饰北斋), Utagawa Hiroshige (歌川广重)
- 适合：和风、浪纹、传统装饰

### 超现实主义
Salvador Dali, Rene Magritte, Frida Kahlo
- 适合：创意、梦幻、概念设计

### 波普/街头
Banksy, Andy Warhol, Basquiat, Keith Haring
- 适合：潮流、涂鸦、社交素材

### 摄影/电影感
Ansel Adams, Steve McCurry, Tim Burton, Wes Anderson
- 适合：风景、纪实人文、怪诞

### 印象派
Claude Monet, Pierre-Auguste Renoir, Edgar Degas
- 适合：光影、花园、沐浴阳光的场景

### 建筑美学
Tadao Ando (安藤忠雄), Zaha Hadid, Frank Gehry
- 适合：城市地标、空间设计、极简几何

## 城市×风格配对建议

| 城市类型 | 推荐风格 | 理由 |
|---------|---------|------|
| 江南水乡（苏州/乌镇/周庄） | 吴冠中 / 宫崎骏 | 白墙黑瓦+水巷=天然水墨/治愈 |
| 现代都市（上海/深圳/广州） | Moebius / James Jean | 摩天楼+科技感=赛博东方/超现实 |
| 历史古都（西安/洛阳/南京/北京） | 吴冠中 / Caravaggio | 古迹+光影=水墨/戏剧光 |
| 山水城市（桂林/杭州/重庆） | 葛饰北斋 / 吴冠中 | 山水+雾=浮世绘/水墨 |
| 悠闲生活城市（成都/大理/昆明） | 宫崎骏 / 葛饰北斋 | 慢生活+自然=治愈/浮世绘 |
| 工业城市（东莞/佛山/苏州工业园） | 吴冠中 / Moebius | 新旧对比=水墨传统+赛博现代 |

## 双风格融合写法

```markdown
in the artistic style of {风格1} + {风格2} — {描述融合效果}
# 示例：
in the artistic style of Wu Guanzhong + Moebius — 水墨线条勾勒机械细节，传统与现代的视觉对话
in the artistic style of Hayao Miyazaki + James Jean — 宫崎骏的温暖底色上叠加James Jean的繁复花卉线条
```
