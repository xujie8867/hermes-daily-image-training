## 详细参数速查

### 1. 清纯生活照 (clean-lifestyle)
- **五官**: 初恋感淡颜 / 邻家清秀脸
- **气质**: 清纯、温柔、自然、安静、亲近、干净
- **场景**: 咖啡馆 / 窗边 / 浅色卧室 / 书桌边
- **服装**: 白色或米白针织开衫 + 浅色内搭；浅色衬衫 + 牛仔裤；奶油白针织上衣 + 半裙
- **光线**: 柔和自然光 / 奶油暖白自然光 / 窗边低反差光
- **滤镜**: 奶油暖白生活剧照滤镜
- **画幅**: 2:3 (1024×1536)
- **镜头**: 半身近景 / 半身到大腿 / 自然坐姿
- **安全边界**: 内搭完整，不透明，不情趣化；不幼态化/学生妹感

### 2. 纯欲曲线生活照 (pure-desire-curve)
- **五官**: 清冷淡颜 / 邻家清秀脸
- **气质**: 清纯、纯欲、安静、克制、柔和、有吸引力
- **场景**: 窗边 / 靠墙 / 卧室床边 / 落地窗边 / 海边步道
- **服装**: 贴身吊带背心 + 低腰短裤；短款针织上衣 + 浅色短裤
- **光线**: 冷白低反差自然光 / 柔和冷白自然光
- **滤镜**: 冷白纯欲生活剧照滤镜
- **画幅**: 2:3 (1024×1536)
- **镜头**: 半身到大腿 / 大腿以上构图 / 轻侧身站姿
- **安全边界**: ⚠️ 严格：不得裸露/情趣化/挑逗姿势；用 `lace top`/`curvy body` 不用 `bikini`/`hourglass`

### 3. 都市时尚写真 (urban-fashion)

- **场景**: 城市街边 / 玻璃橱窗前 / 咖啡店外 / 现代建筑街区
- **服装**: 白衬衫+高腰牛仔裤；西装外套+内搭+长裤；风衣+半裙
- **光线**: 城市自然光 / 柔和街边光 / 阴天低反差自然光 / 玻璃反射柔光
- **滤镜**: 高级都市街拍滤镜
- **画幅**: 2:3 (1024×1536)
- **镜头**: 全身构图 / 半身到大腿 / 大半身 / 自然街拍站姿

## 使用方式

### 生成完整提示词
当选中一条风格后，按以下字段构建 prompt：

```
风格：[style_name]
五官：[五官方向]
气质：[气质标签]
场景：[场景方向]
服装：[服装方向]
光线：[光线氛围]
滤镜：[滤镜效果]
画幅：2:3 (1024×1536)
镜头：[镜头方向]
```

再套用 daily-image-training 的五段式结构公式 + 正约束 + 负面约束。

### 随机选取
```python
import random
styles = ["clean-lifestyle", "pure-desire-curve", "urban-fashion", ...]
chosen = random.choice(styles)
```

### 硬性安全规则
- 人物必须是 20-28 岁明确成年东方女性（所有风格）
- 服装完整，不透明/不情趣化（所有风格）
- 不幼态化/不学生妹感（所有风格）
- Curve 类（纯欲曲线/东方丰腴）额外严格：不做挑逗姿势/不裸露/不过度暴露
